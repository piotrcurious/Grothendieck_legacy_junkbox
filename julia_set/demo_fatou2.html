CMV / OPUC context

A genuine CMV matrix is unitary and is built from Verblunsky coefficients. This visualizer uses a CMV-inspired polynomial recurrence, not a literal CMV matrix spectral solver.

Toda lattice context

The classical Toda flow evolves Jacobi-matrix coefficients isospectrally. Here the parameter modulates a recurrence; no time-integrated Toda flow is solved.

These labels distinguish the mathematical inspiration from the actual numerical map being rendered.

Polynomial dynamics

The iterated map is f(z) = P(z) + c. The generated P is defined by the selected recurrence; it is not automatically an orthogonal polynomial for a specified measure.

Escape potential

For a polynomial of degree d ≥ 2, the Green function is defined by the limit of d⁻ⁿ log⁺|fⁿ(z)|. The displayed escape estimate is numerical and should not be interpreted as a certified capacity calculation.
