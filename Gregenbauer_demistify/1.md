## 2. Core Formulations

1. **Quotient Algebra & Hilbert Series:**
   $$R(Q) = \mathbb{C}[z_1, \dots, z_d]/(q), \quad q = \sum_{i=1}^d z_i^2, \quad \dim V_n = [t^n] \frac{1-t^2}{(1-t)^d}.$$

2. **Spherical Zonal Function Normalization:**
   $$C_n^{(\lambda)}(1) = \frac{(2\lambda)_n}{n!}, \qquad \phi_n(x) = \frac{C_n^{(\lambda)}(x)}{C_n^{(\lambda)}(1)}, \qquad \dim V_n = \frac{n+\lambda}{\lambda} C_n^{(\lambda)}(1).$$

3. **Three Equivalent Differential Operators:**
   - Algebraic $L_x$: $(1-x^2)\phi'' - (2\lambda+1)x\phi' + E_n\phi = 0$, where $E_n = n(n+2\lambda)$.
   - Compact Radial $L_\theta$: $\phi'' + 2\lambda\cot\theta \, \phi' + E_n\phi = 0$.
   - Sturm-Liouville $H_\lambda$: $-u'' + \lambda(\lambda-1)\csc^2\theta \, u = N_n^2 u$, where $N_n^2 = (n+\lambda)^2 = E_n + \lambda^2$.

4. **Bounded Jacobi Operator $M_x$ on $\mathcal{H}^K$:**
   $$M_x \phi_n = a_n \phi_{n+1} + b_n \phi_{n-1}, \qquad a_n = \frac{n+2\lambda}{2(n+\lambda)}, \quad b_n = \frac{n}{2(n+\lambda)} \quad (a_n + b_n = 1 \text{ exactly}).$$

5. **Two-Endpoint Singular Scaling:**
   $$z_+ = (n+\lambda)\theta, \qquad z_- = (n+\lambda)(\pi - \theta).$$
   - North Pole ($z_+ = O(1)$): $\phi_n \sim \mathcal{J}_{\lambda-1/2}(z_+)$.
   - South Pole ($z_- = O(1)$): $\phi_n \sim (-1)^n \mathcal{J}_{\lambda-1/2}(z_-)$.
   - Interior ($z_+, z_- \gg 1$): $\phi_n \sim \frac{2^\lambda \Gamma(\lambda+1/2)}{\sqrt{\pi}} \frac{\cos((n+\lambda)\theta - \lambda\pi/2)}{(n\sin\theta)^\lambda}$.

6. **Verification Invariants:**
   - $\phi_n(1) = 1$, $\phi_n(-1) = (-1)^n$, $\phi_n(-x) = (-1)^n \phi_n(x)$.
   - Exact derivative anchor: $\phi_n'(1) = \frac{n(n+2\lambda)}{2\lambda+1}$.
