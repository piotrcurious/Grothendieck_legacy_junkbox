This manuscript provides the unified algebraic, geometric, and numerical foundation for Gegenbauer polynomials $C_n^{(\lambda)}(x)$ and zonal spherical functions $\phi_n(x)$ on $SO(d)/SO(d-1)$ ($\lambda = \frac{d-2}{2}$).

## 2. Geometry & Graded Quotient Algebra

The representation space $V_n \cong \mathcal{H}_n(\mathbb{R}^d)$ of degree-$n$ spherical harmonics is the $n$-th graded piece of the coordinate ring of the projective null quadric $Q^{d-2} = \{[z] \in \mathbb{P}^{d-1} : \sum z_i^2 = 0\}$:
$$R(Q) = \mathbb{C}[z_1, \ldots, z_d] / (q), \qquad q = \sum_{i=1}^d z_i^2.$$

Graded piece:
$$V_n \cong R(Q)_n \cong \operatorname{Sym}^n(\mathbb{C}^d) / q \operatorname{Sym}^{n-2}(\mathbb{C}^d).$$

Hilbert series:
$$H_{R(Q)}(t) = \sum_{n=0}^\infty (\dim V_n) t^n = \frac{1 - t^2}{(1 - t)^d}.$$

Extracting $\dim V_n$:
$$\dim V_n = [t^n] \frac{1 - t^2}{(1 - t)^d} = \binom{n+d-1}{d-1} - \binom{n+d-3}{d-1} = \frac{2n + d - 2}{n + d - 2} \binom{n + d - 2}{d - 2}.$$

## 3. The Three Exact Equations

1. **Compact Radial Equation:**
   $$\phi'' + 2\lambda\cot\theta\,\phi' + n(n+2\lambda)\phi = 0.$$

2. **Half-Density Equation ($u_n = (\sin\theta)^\lambda \phi_n$):**
   $$-u'' + \lambda(\lambda-1)\csc^2\theta\,u = N^2 u, \qquad N = n+\lambda.$$

3. **Tangent-Limit Equation ($\theta = z/N$):**
   $$\Phi'' + \frac{2\lambda}{z}\Phi' + \Phi = 0 \implies \Phi(z) = \mathcal{J}_{\lambda-1/2}(z).$$

## 4. Degree-Shifting Recurrence Operator

Let $M_x: f(x) \mapsto x f(x)$. For normalized functions $\phi_n(x) = C_n^{(\lambda)}(x) / C_n^{(\lambda)}(1)$:
$$M_x \phi_n = a_n \phi_{n+1} + b_n \phi_{n-1}, \qquad a_n = \frac{n+2\lambda}{2(n+\lambda)}, \quad b_n = \frac{n}{2(n+\lambda)} \quad (a_n + b_n = 1).$$

Production Recurrence Algorithm:
$$\phi_{n+1}(x) = \frac{2(n+\lambda)}{n+2\lambda} x \phi_n(x) - \frac{n}{n+2\lambda} \phi_{n-1}(x).$$

## 5. Numerical Operational Map & Validation

$$\begin{array}{ccc}
\text{Generic } x \in (-1,1) &\rightarrow& \text{Three-term normalized recurrence } \phi_n(x) \\
x \approx \pm 1 &\rightarrow& \text{Endpoint Bessel scaling } \mathcal{J}_{\lambda-1/2}(N\theta) \\
1 \ll N\theta \ll N &\rightarrow& \text{Matched asymptotics} \\
N\theta \gg 1 &\rightarrow& \text{Interior WKB oscillatory wave}
\end{array}$$

Exact Anchors:
- $d=3, \lambda=1/2 \implies \phi_n = P_n(x)$ (Legendre).
- $d=4, \lambda=1 \implies \phi_n(\theta) = \frac{\sin((n+1)\theta)}{(n+1)\sin\theta}$ (Unnormalized $U_n$).
- $d=5, \lambda=3/2 \implies C_n^{(3/2)}(x) = P_{n+1}'(x)$.
