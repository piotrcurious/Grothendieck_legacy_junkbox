# Gegenbauer Demystified: VIII-Layer Architectural Pipeline and Computational Solver

This manuscript provides the unified algebraic, geometric, and numerical foundation for Gegenbauer polynomials $C_n^{(\lambda)}(x)$, zonal spherical functions $\phi_n(x)$, and orthonormal Jacobi basis functions $e_n(x)$ on $SO(d)/SO(d-1)$ ($\lambda = \frac{d-2}{2}$, $d \ge 3$).

## 2. Core Formulations

1. **Quotient Algebra & Hilbert Series:**
   $$R(Q) = \mathbb{C}[z_1, \dots, z_d]/(q), \quad q = \sum_{i=1}^d z_i^2, \quad \dim \mathcal{H}_n(\mathbb{C}^d) = [t^n] \frac{1-t^2}{(1-t)^d} = \binom{n+d-1}{d-1} - \binom{n+d-3}{d-1},$$
   with binomial coefficient zeroing convention $\binom{r}{d-1} = 0$ for $r < d - 1$ (or $\operatorname{Sym}^m(\mathbb{C}^d) = 0$ for $m < 0$), ensuring uniform validity for $n=0, 1$. Harmonic polynomial restriction $\mathcal{H}_n(\mathbb{C}^d) \to \mathscr{Y}_n^\mathbb{C}(S^{d-1})$ maps to complex spherical harmonics.

2. **Spherical Zonal Function Normalization, Parity & Boundedness:**
   $\phi_n$ is $K$-bi-invariant with radial representative $\phi_n(x) \in C^\infty([-1, 1])$ ($x = \cos\theta$), satisfying global parity $\phi_n(-x) = (-1)^n \phi_n(x)$ and boundedness $|\phi_n(x)| \le 1$:
   $$C_n^{(\lambda)}(1) = \frac{(2\lambda)_n}{n!}, \qquad \phi_n(x) = \frac{C_n^{(\lambda)}(x)}{C_n^{(\lambda)}(1)}, \qquad \dim \mathcal{H}_n(\mathbb{C}^d) = \frac{n+\lambda}{\lambda} C_n^{(\lambda)}(1).$$

3. **Three Distinct Polynomial/Spherical Types & Dual Recurrences:**
   - Unnormalized $C_n^{(\lambda)}(x)$.
   - Normalized zonal spherical $\phi_n(x) = C_n(x)/C_n(1)$ ($\phi_n(1)=1$).
   - Orthonormal Jacobi $e_n(x) = h_n \phi_n(x)$ where $h_n = \|\phi_n\|_\lambda^{-1}$ ($\|e_n\|_\lambda=1$).
   - **Dual Recurrence Conversion Invariant:** $x \phi_n = a_n \phi_{n+1} + b_n \phi_{n-1}$ ($a_n = \frac{n+2\lambda}{2(n+\lambda)}, b_n = \frac{n}{2(n+\lambda)}$) converts to orthonormal Jacobi basis recurrence:
     $$x e_0 - \alpha_0 e_1 = 0 \quad (n=0); \qquad x e_n - \alpha_n e_{n+1} - \alpha_{n-1} e_{n-1} = 0 \quad (n \ge 1)$$
     via exact symbolic identity:
     $$\alpha_n^2 = a_n b_{n+1} = \frac{(n+1)(n+2\lambda)}{4(n+\lambda)(n+\lambda+1)}, \qquad I_{\text{dual}}(n) = \alpha_n^2 - a_n b_{n+1} \equiv 0.$$

4. **Symmetric Jacobi Spectral Operator $J = J^*$ on Orthonormal Basis:**
   $$M_x e_n = \alpha_n e_{n+1} + \alpha_{n-1} e_{n-1}, \qquad \alpha_n = \frac{1}{2} + \frac{\lambda(1-\lambda)}{4n^2} + O(n^{-3}) \quad \text{as } n \to \infty \quad (\text{fixed } \lambda).$$
   Matrix properties: $\|J\| = 1$ and $\sigma(J) = [-1, 1]$ as consequences of unitary equivalence to $M_x$; $\|J_m\| < 1$ derived self-containedly via quadratic form positivity on $S^{m-1}$.

5. **Exact Quadrature Moment & Norm Isometry Invariants:**
   $$\int_{-1}^1 x^{2r}(1-x^2)^{\lambda-1/2} dx = B\left(r + \frac{1}{2}, \lambda + \frac{1}{2}\right), \qquad \|T_\lambda S_\lambda f\|_{L^2(0,\pi)} = \|f\|_{\mathcal{H}_\lambda} \implies \|u_n\|_{L^2(0,\pi)}^2 = \|\phi_n\|_\lambda^2.$$

6. **Operator Domain Boundaries & Singular Sturm-Liouville Extensions:**
   - Domain Precedence Classifier: $\operatorname{Classify}(\lambda) = \operatorname{PhysicalClassifier}(\lambda)$ if $\lambda \in \texttt{PhysicalSphereDomain}$ else $\operatorname{AnalyticClassifier}(\lambda)$.
   - Physical sphere parameter family: $d \ge 3 \implies \lambda \in \{1/2, 1, 3/2, 2, \dots\}$.
   - Two-sided LP condition: $\texttt{LP}: \operatorname{coeff}_{+, \text{singular}} \text{ unused}, \operatorname{coeff}_{-, \text{singular}} \text{ unused}$.
   - Unitary transformation: $L^2((0,\pi), (\sin\theta)^{2\lambda}d\theta) \xrightarrow{u=(\sin\theta)^\lambda \phi} L^2(0,\pi)$.
   - Critical case $\lambda=1/2$ ($d=3$): $u \sim A\theta^{1/2} + B\theta^{1/2}\log\theta$ (Friedrichs extension $B=0 \implies u \sim A\theta^{1/2}$).
   - Analytic continuation $0<\lambda<1, \lambda \ne 1/2$: $u \sim A\theta^\lambda + B\theta^{1-\lambda}$ with Friedrichs extension selecting exponent $\max(\lambda, 1-\lambda) = 1/2 + |\lambda - 1/2|$ ($B=0$ for $\lambda>1/2$; $A=0$ for $0<\lambda<1/2$).

7. **Finite-Field Certificates & Denominator Separation:**
   - Separated denominators: $D_{\text{rec}}$ (recurrence), $D_{\text{norm}}$ (normalization), $D_{\text{eval}}$ (point $r$).
   - Explicit hierarchy: $\texttt{PolyEvaluationCertificate}(p, n, x) = \texttt{PolyCertificate}(p, n) \land \texttt{PointCertificate}(p, x)$.
   - $\texttt{ZonalCertificate}(p, \text{plan}, \text{degree}=n, \text{point}=x=c/r) = \texttt{PolyEvaluationCertificate}(p, n, x) \land (p \nmid v_n) \land (p \nmid u_n)$.

8. **Typed Separation & Error Bounds:**
   - First-class type distinction: `ExactValue` != `ErrorBound` != `Residual`.
   - `TheoremStatus` Enum: `ALGEBRAIC_EXACT`, `ARITHMETIC_EXACT`, `ANALYTIC_CERTIFIED`, `NUMERICAL_CERTIFIED`, `EMPIRICAL_DIAGNOSTIC`.
   - Decomposed error bound: $E_{\text{total}} \le E_{\text{analytic}} + E_{\text{arithmetic}} + E_{\text{conditioning}} + E_{\text{implementation}}$ with $E_{\text{conditioning}} \le \kappa \cdot E_{\text{input}}$.
