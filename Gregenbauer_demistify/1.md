# Gegenbauer Demystified: VIII-Layer Architectural Pipeline and Computational Solver

This manuscript provides the unified algebraic, geometric, and numerical foundation for Gegenbauer polynomials $C_n^{(\lambda)}(x)$ and zonal spherical functions $\phi_n(x)$ on $SO(d)/SO(d-1)$ ($\lambda = \frac{d-2}{2}$, $d \ge 3$).

## 2. Core Formulations

1. **Quotient Algebra & Hilbert Series:**
   $$R(Q) = \mathbb{C}[z_1, \dots, z_d]/(q), \quad q = \sum_{i=1}^d z_i^2, \quad \dim V_n = [t^n] \frac{1-t^2}{(1-t)^d}.$$

2. **Spherical Zonal Function Normalization:**
   $$C_n^{(\lambda)}(1) = \frac{(2\lambda)_n}{n!}, \qquad \phi_n(x) = \frac{C_n^{(\lambda)}(x)}{C_n^{(\lambda)}(1)}, \qquad \dim V_n = \frac{n+\lambda}{\lambda} C_n^{(\lambda)}(1).$$

3. **Three Equivalent Differential Operators:**
   - Algebraic $L_x$: $(1-x^2)\phi'' - (2\lambda+1)x\phi' + E_n\phi = 0$, where $E_n = n(n+2\lambda)$.
   - Compact Radial $L_\theta$: $\phi'' + 2\lambda\cot\theta \, \phi' + E_n\phi = 0$.
   - Sturm-Liouville $H_\lambda$: $-u'' + \lambda(\lambda-1)\csc^2\theta \, u = N_n^2 u$, where $N_n^2 = (n+\lambda)^2 = E_n + \lambda^2$.

4. **Symmetric Jacobi Spectral Operator $J = J^*$ on Orthonormal Basis:**
   $$M_x e_n = \alpha_n e_{n+1} + \alpha_{n-1} e_{n-1}, \qquad \alpha_n = \frac{1}{2} \sqrt{\frac{(n+1)(n+2\lambda)}{(n+\lambda)(n+\lambda+1)}} = \frac{1}{2} + O(n^{-2}).$$
   Matrix properties: $J = J^*, \|J\| = 1, \sigma(J) = [-1, 1]$. Sanity check for $\lambda=0.5$: $\alpha_0 = 1/\sqrt{3}$.

5. **Two-Overlap Composite Uniform Asymptotics:**
   $$F_{\text{comp}} = F_{\text{north}}(z_+) + F_{\text{south}}(z_-) + F_{\text{interior}}(N, \theta) - F_{+,\text{overlap}}(z_+) - F_{-,\text{overlap}}(z_-).$$

6. **Exact Derivative Anchors & Derivatives:**
   $$\phi_n^{(k)}(x) = \frac{2^k (\lambda)_k}{C_n^{(\lambda)}(1)} C_{n-k}^{(\lambda+k)}(x) \quad (k \le n), \qquad \phi_n^{(k)}(x) \equiv 0 \quad (k > n),$$
   $$\phi_n'(1) = \frac{n(n+2\lambda)}{2\lambda+1}, \qquad \phi_n'(-1) = (-1)^{n-1} \frac{n(n+2\lambda)}{2\lambda+1}.$$

7. **Field Extensions $\mathbb{Q}(\lambda, x)$ & Exact Algebraic Stability:**
   - **Three-term Recurrence:** $C_0^{(\lambda)}(x) = 1$, $C_1^{(\lambda)}(x) = 2\lambda x$, $n C_n^{(\lambda)}(x) = 2(n+\lambda-1)x C_{n-1}^{(\lambda)}(x) - (n+2\lambda-2) C_{n-2}^{(\lambda)}(x)$. All operations remain in $\mathbb{Q}(\lambda, x)$, bypassing Gamma and factorials.
   - **Derivative Generation:** $y' = \frac{d}{dx} C_n^{(\lambda)}(x) = 2\lambda C_{n-1}^{(\lambda+1)}(x)$, and $y'' = \frac{(2\lambda+1)x y' - n(n+2\lambda)y}{1-x^2}$.
   - **Gauss-Gegenbauer Quadrature:** $\int_{-1}^1 f(x)(1-x^2)^{\lambda-1/2} dx \approx \sum_{k=1}^n w_k f(x_k)$, with algebraic nodes $x_k$ and weights $w_k = \mu_0 v_{k,1}^2$ computed via Golub-Welsch matrix eigenvalue spectral decomposition.
